Event Log ⭐

This is the interesting rabbit hole. 😂

The document shows that the DCRG8 has an event pointer/counter:

Address	Description
5030H	Event Pointer / Event Counter

The procedure:

Read register 5030H using Function 04.
The returned value contains:
MSB = event counter
LSB = pointer to last stored event
Write the desired event number back to 5030H using Function 06.
Read event text from 5032H using Function 04.

The event description requires reading 43 registers from 5032H. The returned data contains:

first 10 bytes = date
byte 11 = separator
bytes 12–19 = time
byte 20 = separator
remaining bytes = event text
